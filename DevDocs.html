📋 Project Overview

Purpose

Assistive Classroom is an AI-powered camera system designed to help students with vision or hearing difficulties access classroom content in real-time. The system captures video from various sources and uses vision-language models to:

  • Read text from slides or whiteboards
  • Describe visual content
  • Summarize key points
  • Answer custom questions about the content

Technology Stack

Component Technology Version Purpose
Backend Flask 3.0.0 RESTful API server
Frontend Gradio 4.0+ Web UI framework
Video Processing OpenCV 4.8.1 Camera capture & MJPEG streaming
Local LLM Transformers + BLIP 4.36.2 Free image captioning
Cloud LLM OpenAI / Anthropic Latest High-quality vision AI

Current Status

✅ Fully Functional Core Features:
  • Laptop camera capture with live MJPEG streaming
  • Multi-provider LLM support (local, OpenAI, Claude)
  • Real-time frame processing
  • QR code generation for easy phone setup
  • Colored, structured logging
  • Network interface detection
⚠️ Known Limitations:
  • Phone camera requires HTTPS (browser security policy)
  • Local BLIP model has limited OCR capabilities
  • No continuous processing mode yet (manual trigger only)
  • No text-to-speech output

Logging System

Custom colored logging formatter for better readability:

class ColoredFormatter(logging.Formatter):
    COLORS = {
        'DEBUG': '\033[94m',    # Blue
        'INFO': '\033[92m',     # Green
        'WARNING': '\033[93m',  # Yellow
        'ERROR': '\033[91m',    # Red
        'CRITICAL': '\033[95m', # Magenta
    }

    def format(self, record):
        levelname = record.levelname
        if levelname in self.COLORS:
            record.levelname = f"{self.COLORS[levelname]}{levelname}{self.RESET}"
        return super().format(record)
💡 Logging Best Practice: Only log significant events (startup, errors, user actions). Frame-by-frame logging was removed to reduce noise.

📹 Camera System Implementation

Camera Handler Architecture

The CameraHandler class is a singleton that manages all camera sources:

class CameraHandler:
    def __init__(self):
        self.camera = None              # OpenCV VideoCapture object
        self.source_type = None         # 'laptop', 'phone', 'ip'
        self.frame_queue = queue.Queue(maxsize=100)
        self.current_frame = None       # Most recent frame
        self.is_running = False         # Capture loop control
        self.lock = Lock()              # Thread safety
        self.thread = None              # Background capture thread

Laptop Camera Capture

Uses OpenCV's VideoCapture with a background thread:

def start_laptop_camera(self, camera_index=0):
    self.camera = cv2.VideoCapture(camera_index)
    self.camera.set(cv2.CAP_PROP_FRAME_WIDTH, config['CAMERA_WIDTH'])
    self.camera.set(cv2.CAP_PROP_FRAME_HEIGHT, config['CAMERA_HEIGHT'])
    self.camera.set(cv2.CAP_PROP_FPS, config['CAMERA_FPS'])

    self.is_running = True
    self.thread = Thread(target=self._capture_loop, daemon=True)
    self.thread.start()

def _capture_loop(self):
    while self.is_running:
        ret, frame = self.camera.read()
        if ret:
            with self.lock:
                self.current_frame = frame.copy()  # CRITICAL: copy frame
            if not self.frame_queue.full():
                self.frame_queue.put(frame.copy())
🐛 Critical Bug Fixed: Initially, self.current_frame = frame stored a direct reference. As OpenCV reuses the buffer, frames were corrupted. Fixed by using frame.copy() to create independent copies.

Phone Camera Receiver

Receives JPEG frames via HTTP POST from browser:

def receive_phone_frame(self, frame_data):
    # Validate frame data
    if not frame_data or len(frame_data) == 0:
        return False

    # Decode JPEG binary data
    nparr = np.frombuffer(frame_data, np.uint8)
    frame = cv2.imdecode(nparr, cv2.IMREAD_COLOR)

    # Validate decoded frame
    if frame is None or frame.shape[0] < 100:
        return False

    with self.lock:
        self.current_frame = frame.copy()  # Thread-safe copy
        self.source_type = 'phone'

        if not self.frame_queue.full():
            self.frame_queue.put(frame.copy())

MJPEG Streaming

Generates continuous MJPEG stream for frontend video display:

def generate_mjpeg_stream(self):
    blank_frame = np.zeros((480, 640, 3), dtype=np.uint8)

    while True:
        frame = self.get_current_frame()

        # Use blank frame if no camera active
        if frame is None:
            frame = blank_frame

        try:
            # Encode as JPEG with 85% quality
            ret, buffer = cv2.imencode('.jpg', frame,
                                      [cv2.IMWRITE_JPEG_QUALITY, 85])
            if ret:
                frame_bytes = buffer.tobytes()
                # MJPEG multipart format
                yield (b'--frame\r\n'
                       b'Content-Type: image/jpeg\r\n\r\n'
                       + frame_bytes + b'\r\n')
        except Exception as e:
            logger.error(f"JPEG encoding failed: {e}")

        time.sleep(0.033)  # ~30 FPS

Thread Safety

Critical sections are protected with locks:

  • self.current_frame access (read/write)
  • self.source_type updates
  • Camera state transitions
⚠️ Performance Note: frame.copy() adds ~1ms overhead per frame, but prevents race conditions. At 30 FPS, this is negligible (3% CPU overhead).

🤖 LLM Integration

Video Processor Architecture

The VideoProcessor class abstracts multiple LLM providers:

class VideoProcessor:
    def __init__(self):
        self.local_model = None
        self.local_processor = None

    def process_frame(self, frame, task, provider=None, custom_prompt=None):
        if provider == 'local':
            return self.process_with_local_model(frame, task)
        elif provider == 'openai':
            return self.process_with_openai(frame, prompt)
        elif provider == 'claude':
            return self.process_with_claude(frame, prompt)

Local Model (BLIP)

Salesforce BLIP model for CPU-based image captioning:

def _load_local_model(self):
    from transformers import BlipProcessor, BlipForConditionalGeneration

    model_name = 'Salesforce/blip-image-captioning-base'
    self.local_processor = BlipProcessor.from_pretrained(model_name)
    self.local_model = BlipForConditionalGeneration.from_pretrained(model_name)

def process_with_local_model(self, frame, task):
    # Convert OpenCV BGR to PIL RGB
    frame_rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    pil_image = Image.fromarray(frame_rgb)

    # Generate caption
    inputs = self.local_processor(pil_image, return_tensors="pt")
    out = self.local_model.generate(**inputs, max_length=50)
    description = self.local_processor.decode(out[0], skip_special_tokens=True)

    return {'success': True, 'text': description, 'provider': 'local'}

OpenAI GPT-4 Vision

def process_with_openai(self, frame, prompt):
    import openai

    # Convert frame to base64 JPEG
    base64_image = self._frame_to_base64(frame)

    client = openai.OpenAI(api_key=config['OPENAI_API_KEY'])
    response = client.chat.completions.create(
        model='gpt-4o',
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": prompt},
                {
                    "type": "image_url",
                    "image_url": {
                        "url": f"data:image/jpeg;base64,{base64_image}",
                        "detail": "high"
                    }
                }
            ]
        }],
        max_tokens=500
    )

    return {
        'success': True,
        'text': response.choices[0].message.content,
        'provider': 'openai'
    }

Claude Vision

def process_with_claude(self, frame, prompt):
    import anthropic

    base64_image = self._frame_to_base64(frame)

    client = anthropic.Anthropic(api_key=config['CLAUDE_API_KEY'])
    message = client.messages.create(
        model='claude-3-5-sonnet-20241022',
        max_tokens=1024,
        messages=[{
            "role": "user",
            "content": [
                {
                    "type": "image",
                    "source": {
                        "type": "base64",
                        "media_type": "image/jpeg",
                        "data": base64_image
                    }
                },
                {"type": "text", "text": prompt}
            ]
        }]
    )

    return {
        'success': True,
        'text': message.content[0].text,
        'provider': 'claude'
    }

Phone URL Detection

Frontend detects if backend is localhost and replaces with actual IP:

def _get_phone_url(self):
    from urllib.parse import urlparse
    parsed = urlparse(BACKEND_URL)

    # If backend is localhost, use actual network IP
    if parsed.hostname in ['localhost', '127.0.0.1']:
        local_ip = get_local_ip()
        return f"{parsed.scheme}://{local_ip}:{parsed.port}/phone"
    else:
        return f"{BACKEND_URL}/phone"

🐛 Critical Bugs Fixed

Bug #1: Frame Corruption (Black Screen)

Symptom: Laptop camera showed black screen or corrupted video

Root Cause

In camera_handler.py, line 83:

# BEFORE (BROKEN):
self.current_frame = frame  # Direct reference

# AFTER (FIXED):
self.current_frame = frame.copy()  # Independent copy

Technical Explanation

OpenCV's VideoCapture.read() returns a reference to an internal buffer that gets reused. Without .copy():

  1. Frame 1 captured → self.current_frame points to buffer
  2. Frame 2 captured → OpenCV overwrites buffer with new data
  3. self.current_frame now points to Frame 2's data (corrupted)
  4. MJPEG encoder reads corrupted data → black output

Bug #2: Phone Camera Port Mismatch

Symptom: Phone camera frames sent to wrong port, backend never received them

Root Cause

In phone_camera.html, line 130:

// BEFORE (BROKEN):
const BACKEND_URL = window.location.protocol + '//' +
                    window.location.hostname + ':5000';

// AFTER (FIXED):
const BACKEND_URL = window.location.protocol + '//' +
                    window.location.hostname + ':' +
                    window.location.port;

Impact

User was running backend on port 6969, but phone page hardcoded port 5000. All phone frames were being sent to the wrong port and getting rejected.

Bug #3: Frozen Video Feed

Symptom: Video displayed once at startup, then froze

Root Cause

Frontend called get_video_frame() only once when camera started:

# BEFORE (BROKEN):
start_laptop_btn.click(
    fn=self.start_laptop_camera,
    inputs=[camera_index],
    outputs=[camera_status, video_output]  # Updates once only!
)

# AFTER (FIXED):
# Use HTML img tag with direct MJPEG stream
video_output = gr.HTML(
    value=f'<img src="{BACKEND_URL}/api/camera/stream" />'
)
# Stream auto-updates at 30 FPS, no manual refresh needed

Bug #4: Excessive Logging

Symptom: Terminal flooded with per-frame debug messages

Fixed By

  • Removed logger.debug("Phone frame received") from hot path
  • Only log significant events (camera start/stop, errors)
  • Added colored logging for better visual parsing

Bug #5: Phone Camera getUserMedia Undefined

Symptom: "navigator.mediaDevices.getUserMedia is undefined"

Root Cause

Modern browsers require HTTPS for camera access (except localhost). HTTP connections get undefined API.

Fix

// Check if API is available
if (!navigator.mediaDevices || !navigator.mediaDevices.getUserMedia) {
    throw new Error('Camera API not available. HTTPS required.');
}

// Check if page is secure
if (window.location.protocol !== 'https:' &&
    window.location.hostname !== 'localhost') {
    updateStatus('⚠️ HTTPS Required', 'error');
    return;
}

🔒 HTTPS Setup Guide

Why HTTPS is Required

Modern browsers restrict navigator.mediaDevices.getUserMedia() to secure contexts for privacy:

  • ✅ https:// connections
  • ✅ localhost (any port)
  • ❌ http:// over network (e.g., http://192.168.1.3:6969)

Option 1: Self-Signed Certificate (Development)

Generate Certificate

openssl req -x509 -newkey rsa:4096 -nodes \
  -keyout key.pem -out cert.pem -days 365 \
  -subj "/CN=192.168.1.3"

Update Flask Server

# In run.py
app.run(
    host=host,
    port=port,
    debug=debug,
    ssl_context=('cert.pem', 'key.pem')  # Add this
)

Access on Phone

  1. Open https://192.168.1.3:6969/phone
  2. Browser shows certificate warning
  3. Click "Advanced" → "Proceed Anyway"
  4. Grant camera permissions
⚠️ Warning: Self-signed certificates are insecure. Only use for testing on trusted networks.

⚡ Performance Analysis

Backend Performance

Operation Latency Bottleneck Optimization
Camera Capture (OpenCV) ~33ms (30 FPS) Camera hardware None needed
Frame Copy ~1ms Memory bandwidth Unavoidable (prevents corruption)
JPEG Encoding ~5-10ms CPU Quality=85 (balanced)
MJPEG Streaming ~1ms Network Local network only
Local BLIP (CPU) ~500ms CPU Use GPU if available
OpenAI API ~2-4s Network + API None (external)
Claude API ~2-3s Network + API None (external)

Memory Usage

  • Base Backend: ~200 MB (Flask + OpenCV)
  • + BLIP Model: +1.2 GB (loaded on first use)
  • + Frame Queue: ~100 MB (100 frames @ 1280x720)
  • Total (with BLIP): ~1.5 GB RAM

Network Bandwidth

MJPEG Stream: 1280x720 @ 30 FPS, JPEG quality 85%
Frame size: ~50-100 KB (depends on content complexity)
Bandwidth: 1.5-3 MB/s (12-24 Mbps)

Recommendation: Use on local network or reduce resolution for remote access

Optimization Recommendations

For Low-End Hardware

  • Reduce camera resolution: 640x480 instead of 1280x720
  • Lower JPEG quality: 70% instead of 85%
  • Reduce FPS: 15 FPS instead of 30 FPS
  • Use local BLIP model (CPU-only)

For High Performance

  • Use GPU for BLIP: Set LOCAL_MODEL_DEVICE=cuda
  • Use OpenAI/Claude for better quality
  • Increase frame queue size for smoother processing

For Production

  • Use gunicorn with multiple workers
  • Add Redis for caching LLM results
  • Implement rate limiting on API endpoints
  • Use nginx for static file serving and load balancing
